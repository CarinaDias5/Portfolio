# Portefólio Carina Dias

Portefólio estático de página única para Carina Dias, focado em dois projetos
Power BI.

## Projetos

- Projeto BI - E-Commerce Brasileiro
- Análise Avançada de Dados

Os ficheiros `.pbix` estão guardados em `Power BI/` com nomes seguros para a web,
para poderem ser transferidos a partir do site no GitHub Pages.

## Incorporação Power BI

Os relatórios estão configurados em `script.js` com URLs públicos do Power BI
Service. Os ficheiros `.pbix` continuam disponíveis para transferência como
alternativa.
